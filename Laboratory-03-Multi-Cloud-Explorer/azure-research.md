# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud platform, launched in 2010. It integrates seamlessly with Windows, Microsoft 365, and Active Directory — making it the natural choice for organizations already using Microsoft technologies.

## Global Infrastructure
Azure has **60+ regions** — available in more countries than any other cloud provider.

## Cloud Management Console
Manage all services at the Azure Portal at **portal.azure.com**

## Four Core Services
1. **Azure Virtual Machines** — Windows or Linux virtual computers
2. **Azure Blob Storage** — Massive scalable unstructured data storage
3. **Azure SQL Database** — Fully managed Microsoft SQL databases
4. **Microsoft Entra ID** — Identity and access management

## Three Advantages
1. Perfect integration with existing Microsoft products
2. Easy hybrid connection to on-premises servers
3. Often uses existing licenses — no extra purchase needed

## Typical Enterprise Use Cases
- Schools, universities, and government institutions
- Companies already using Windows Server and Office
- Businesses migrating from on-premises datacenters
