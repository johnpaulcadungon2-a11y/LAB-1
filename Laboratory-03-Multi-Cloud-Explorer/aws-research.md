# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's largest and oldest public cloud platform, launched by Amazon in 2006. It offers over 200 services including computing, storage, databases, artificial intelligence, and networking. It serves startups, governments, and global enterprises.

## Global Infrastructure
AWS has **32 geographic regions** worldwide, each with multiple Availability Zones for high reliability.

## Cloud Management Console
Manage all services through the AWS Management Console at **console.aws.amazon.com**

## Four Core Services
1. **Amazon EC2** — Virtual computers (servers) in the cloud
2. **Amazon S3** — Unlimited, scalable storage for files and data
3. **Amazon RDS** — Fully managed relational databases
4. **Amazon VPC** — Isolated private cloud networking

## Three Advantages
1. Widest selection of services and features available
2. Free Tier program allows learning at no cost
3. Scales seamlessly from startup to global enterprise

## Typical Enterprise Use Cases
- Running websites and mobile applications
- Big data analytics and data warehousing
- Global e-commerce and media streaming platforms
