# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform is Google's cloud service, launched in 2008. It runs on the same infrastructure powering Google Search, YouTube, and Gmail. GCP is the industry leader in Artificial Intelligence, machine learning, and containers.

## Global Infrastructure
GCP has **34 regions** worldwide with one of the world's largest private fiber-optic networks.

## Cloud Management Console
Manage all services at **console.cloud.google.com**

## Four Core Services
1. **Google Compute Engine** — High-performance virtual machines
2. **Google Cloud Storage** — Fast, reliable, cost-effective storage
3. **Google Kubernetes Engine (GKE)** — Industry-standard container management
4. **Vertex AI** — Built-in tools for Artificial Intelligence and Machine Learning

## Three Advantages
1. Best platform for AI and Machine Learning
2. Invented Kubernetes — the global standard for containers
3. Fast, modern, and consistently cost-efficient

## Typical Enterprise Use Cases
- Artificial Intelligence and data science projects
- Modern cloud-native applications using containers
- Tech startups and innovative software companies
