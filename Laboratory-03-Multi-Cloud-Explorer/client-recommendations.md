# Client Recommendations

## Client A — Startup Company
**Recommended Platform: AWS**

AWS is ideal for a startup with limited budget but expected growth. The Free Tier allows starting at no cost, and pay-as-you-go pricing keeps expenses low. As the company grows, AWS scales infinitely. They could use:
- **Amazon EC2** — to host their mobile application
- **Amazon S3** — to store user photos and application files
- **Amazon RDS** — to store user data in a managed database

## Client B — University
**Recommended Platform: Microsoft Azure**

Azure is the natural choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Everything works together without buying new tools or retraining staff. They could use:
- **Azure Virtual Machines** — to host university websites
- **Azure SQL Database** — to securely store student records
- **Entra ID** — same login system already in use

## Client C — AI Research Company
**Recommended Platform: Google Cloud Platform**

GCP is the leader in Artificial Intelligence and Machine Learning. It offers the best tools and specialized hardware for AI research. They could use:
- **Vertex AI** — to build, train, and test AI models
- **Compute Engine (GPU instances)** — powerful computers for heavy calculations
- **Cloud Storage** — to store large research datasets

## Client D — Global E-Commerce Company
**Recommended Platform: AWS**

AWS has the most experience serving global enterprises. It has regions worldwide and automatically scales during traffic spikes. They could use:
- **Auto Scaling Groups** — automatically add servers during sales events
- **Amazon S3 + CloudFront** — fast product images worldwide
- **Amazon RDS Multi-AZ** — highly reliable database

## Multi-Cloud Decision Matrix
| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Free Tier available, low entry cost, grows seamlessly |
| Enterprise Organization | AWS | Most mature, widest service selection, proven reliability |
| Microsoft Environment | Azure | Native integration with Windows, AD, and Office 365 |
| AI / Machine Learning | GCP | Industry-leading AI tools and expertise |
| Kubernetes Deployment | GCP | Invented Kubernetes — most mature and standard |
| Global Web Application | AWS | Most regions worldwide, longest track record |
