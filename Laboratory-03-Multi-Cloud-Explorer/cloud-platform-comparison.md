## Questions & Answers

**1. Which cloud provider offers the broadest range of services?**
AWS offers the widest range of services. Launched in 2006, it is the oldest provider with over 200 services across every category. Its long history and massive community have driven deeper development than Azure or GCP.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure integrates best with Microsoft technologies. It was built to work natively with Windows Server, Active Directory, and Microsoft 365. Everything connects without rewriting code or learning new tools.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform leads in both areas. Google invented Kubernetes and created many foundational AI technologies. Their GKE and Vertex AI remain the most mature and respected tools in the industry.

**4. Which cloud platform would you personally choose and why?**
I would choose Google Cloud Platform for modern applications. It feels clean, fast, and built for the future. If I worked at a school or Microsoft-based company, I would choose Azure instead for seamless integration.
