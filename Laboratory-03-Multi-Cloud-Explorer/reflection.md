# Mission Reflection

## Multi-Cloud Explorer Reflection

**Which cloud platform impressed you the most?**
Google Cloud Platform impressed me the most. It feels modern, clean, and built for the future. As the creator of Kubernetes and a leader in Artificial Intelligence, GCP shows where technology is going. It is amazing that the same infrastructure powering Google Search and YouTube is available to anyone.

**What similarities exist among AWS, Azure, and GCP?**
All three platforms work in basically the same way. They all offer virtual computers, file storage, databases, private networks, and user login controls. They all use pay-as-you-go pricing where you only pay for what you use. The core ideas are identical — mostly just the names and menus differ.

**How do business requirements influence cloud platform selection?**
Choosing a cloud provider is not about which one is technically "best." It is about which one fits the client. A startup chooses AWS to save money. A university chooses Azure because they already use Microsoft. An AI company chooses GCP. The business needs — budget, existing tools, and goals — decide the winner.

**What did you learn from acting as a Cloud Solutions Consultant?**
I learned that a cloud consultant does not just pick popular services. You must listen to the client first. You ask: What do you already use? What is your budget? What are you trying to build? Then you match the right cloud platform to their answer. Technology serves the business — not the other way around.

**How has your GitHub Cloud Computing Portfolio improved?**
My portfolio now contains organized research, comparisons, and real recommendations. Anyone looking can see exactly what I learned. Each file builds on the last. I am building a professional reference that I can show to employers. It proves I can research, analyze, document, and recommend cloud solutions.
